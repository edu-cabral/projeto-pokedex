# Pokédex - 1996

## 📝 Descrição do Projeto
um site baseado na franquia Pokémon, com o objetivo de entregar uma Pokédex com todos os Pokémons da região de Kanto (1º Geração), contendo:

* Número da Pokédex
* Ícone da espécie
* Nome da espécie
* Tipo da espécie (Grama, Fogo, Água, etc.)
